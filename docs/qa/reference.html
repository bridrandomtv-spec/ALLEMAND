D Protocole de comparaison (à chaque phase future)

  1. Purge : Ctrl+Maj+R sur l'application (Service Worker v3.48+).
  2. Ouvre cette page dans un onglet, l'application dans un autre, côte à côte.
  3. Règle la largeur à 600 px puis 1024 px puis 1440 px (DevTools → Device Mode).
  4. Pour chaque élément 1→11 : compare fond, cartes, topbar, sidebar, héro, panneaux, grilles, rangée ; coche uniquement si conforme.
  5. Note tout écart (couleur, rayon, espacement, débordement, texte illisible) avant de cocher.
  6. Rejoue la checklist après chaque phase future : toute case décochée = régression à signaler.

E À ne jamais régresser (garde-fous du dépôt)

  • B1 : vue english accessible + tiroir complet en mode anglais.
  • Paywall : go() appelle ACCESS.canAccessView() avant tout rendu.
  • 3AS : exactement 8 Lektionen L1-L8 (164 pages) · 2AS : 212 pages.
  • Thème sombre réversible : retirer data-theme de <html> = retour instantané.
  • D0 perf : polices non bloquantes · SW stale-while-revalidate · livre en idle.
  • R2b : #subjectsHub frère de #matieresBody (aucun écrasement croisé).
  • Navigation : 33 entrées conservées (sidebar 8 primaires + groupes accordéon).
  • Données honnêtes : statuts lus (subjects.json / matieres.json) · progression masquée si vide/agrégée · badge cloche masqué à zéro.
